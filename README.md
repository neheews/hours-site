# hours-site

홀스마(Hours) 앱의 **개인정보처리방침·이용약관을 내는 자리**입니다.
App Store 와 Google Play 가 URL 을 요구하고, 비어 있거나 404 면 제출 자체가
안 됩니다.

> https://neheews.github.io/hours-site/

## 손으로 고치지 마세요

여기 있는 파일은 **앱 저장소에서 복사된 것**입니다. 원본은 그쪽의
`docs/privacy-policy.md` · `docs/terms.md` · `site/` 이고,
`scripts/sync_legal.py` 가 복사하며 검사가 바이트를 대조합니다.
여기서 고치면 다음 동기화에서 덮입니다.

**앱 저장소를 통째로 공개하지 않은 이유**가 이 저장소가 따로 있는 이유입니다.
그쪽 `docs/` 에는 운영 절차와 내부 분석이 함께 있어, Pages 로 올리면
그것까지 나갑니다.
